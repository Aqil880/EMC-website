# EMC-website

# EMC - Excellence in Micro Computing

A modern, responsive website developed for **EMC (Excellence in Micro Computing)**. The project showcases computer repair services, technical training courses, events, and an online registration system.

---

## Features

- Responsive Website
- Modern UI Design
- Mobile Navigation Menu
- Animated Hero Section
- Events Page
- Registration Form
- Client-side Form Validation
- Responsive Layout
- Google Fonts Integration
- Interactive Buttons and Cards

---

## Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)

---

## Pages

### Home Page

- Hero Section

- Contact Section

- Form Validation

```bash

```

Open the project

```bash
cd EMC-Website
```

Run

Simply open

```
index.html
```

in your browser.
